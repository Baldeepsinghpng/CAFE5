# Demo 5: Golden Hour Kitchen (Premium All-Day Brunch)

Bright, modern, lifestyle-led. **Fictional demo brand. Every detail is a placeholder.**

## Preview
Double-click `index.html`.

## Change the basics
- **Name, phone, WhatsApp, map, party size limits:** `CONFIG` block at the top of `script.js`.
- **Menu (Breakfast / Brunch / Salads / Coffee):** lists in `index.html`. Tags `V` and `GF` are demo labels. Only keep dietary labels the kitchen has confirmed.
- **Time slots:** edit the `slot` radio buttons in `index.html`.
- **Colours:** variables at the top of `style.css`.
- **Photos:** search for `images.unsplash.com`.

## Table inquiry form
It checks the fields and shows a demo message. **It does not book or send anything.** A real version needs a form service, a booking tool (many cafes already use one) or a small backend.
